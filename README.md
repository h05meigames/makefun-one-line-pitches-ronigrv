A one-sentence pitch for the
[u-ronigrv-a-day-of-one-line-pitches-12cd9bb3](https://make.fun/bounty/u-ronigrv-a-day-of-one-line-pitches-12cd9bb3)
bounty on [make.fun](https://make.fun/r/0ene8b3q) — convincing a friend who
has never coded to let an AI agent build their first app idea.

## The pitch

> You don't need to learn to code — just describe the app idea you've always wanted in plain words, and an AI agent on make.fun builds a real, working version for you to try, free, while you stay in charge.

## How it works

`main.ts` (Node 22, standard library only) writes the pitch to
`/output/entry.txt` — one sentence, UTF-8, within the 1–240 character
limit. It also prints the same text to stdout.

## Run it

```sh
node main.ts
```
